## 文案撰寫共通規格

依據村長 2026-05-06 指示，每篇 `newDescription` 必須符合：

1. **關鍵字密度**：每篇至少自然嵌入 3 個下列關鍵字 — 春酒佈置、尾牙佈置、品牌活動佈置、活動場景設計、商業空間佈置、婚禮佈置、快閃活動、展區佈置、企業活動。
2. **文體**：活潑生動，破題用情境感（如「燈光一亮，賓客一進場就...」「百貨人潮快速經過，真正能讓人停下腳步的...」），避開制式宣傳語。
3. **三段論結構**：
   - 第一段：情境破題（30-60 字）
   - 第二段：村山良作的設計手法 + 適用場景（80-120 字）
   - 第三段：**CTA 行動呼籲**（30-50 字，例如「想為下一場春酒、尾牙或品牌活動量身打造主題場景？立即透過村花囍 LINE 諮詢／來電預約檔期，讓村山良作把您的故事變成可以被拍下來、被記住的現場。」）
4. **內部連結**：同品牌/同主題系列在文案中提及兄弟篇，例如豪鼎品牌日 2025 文案中可帶入「延續 2022/2023/2024 連續四年品牌日設計合作」。
5. **長度**：220–260 字（與 `album-descriptions-20260505.json` 的 28 篇舊範本一致）。
