## Runtime 資料源

正式站 runtime 資料以 PostgreSQL 為唯一資料源，不再以 JSON 檔作為資料源。

| 類型 | 儲存位置 |
|---|---|
| 作品標題、文案、分類、排序、精選 | PostgreSQL `goodjob_site.articles` |
| 相簿圖片 URL 與順序 | PostgreSQL `goodjob_site.article_images` |
| 獎項資料 | PostgreSQL `goodjob_site.article_awards` |
| 後台帳號 | PostgreSQL `goodjob_site.accounts` |
| 後台權限 | PostgreSQL `goodjob_site.account_permissions` |
| 舊版設定值 | PostgreSQL `goodjob_site.config` |
| 圖片檔本體 | Cloudflare R2：`r2:goodjob-images` |
| 圖片公開 URL | `https://goodjob-img.weddingwishlove.com/` |

`/data/articles.json` 仍可被讀取，但它是由 PostgreSQL 動態輸出，不能再當成可編輯資料檔。

## 重要部署規則

不要部署覆蓋以下 runtime 檔案：

```text
data/articles.json
data/accounts.json
data/config.json
data/goodjob.sqlite3*
```

repo 已用 `.gitattributes` 將上述檔案 `export-ignore`，使用 `git archive` 部署時不會包進去。

正確部署方式：

```bash
cd D:\AI_Code\goodjob-site
git archive --format=tar --output=%TEMP%\goodjob-site.tar HEAD
scp %TEMP%\goodjob-site.tar achilean@100.102.51.64:/tmp/goodjob-site.tar
ssh achilean@100.102.51.64 "tar -xf /tmp/goodjob-site.tar -C /srv/weddingwish/goodjob-sit/ && rm /tmp/goodjob-site.tar && sudo systemctl restart murayama-goodjob.service"
```

不要用整個資料夾 `scp -r *` 覆蓋正式站，尤其不要覆蓋 `data/`。

## systemd 環境變數

主要設定檔：

```text
/etc/systemd/system/murayama-goodjob.service
/etc/systemd/system/murayama-goodjob.service.d/postgres.conf
/etc/systemd/system/murayama-goodjob.service.d/r2.conf
```

必要環境變數：

```text
GOODJOB_DATABASE_URL=dbname=goodjob_site user=achilean
GOODJOB_RCLONE_BIN=/home/achilean/bin/rclone
GOODJOB_R2_REMOTE=r2:goodjob-images
GOODJOB_CDN_DOMAIN=https://goodjob-img.weddingwishlove.com
GOODJOB_WEBP_QUALITY=90
HOME=/home/achilean
```

確認方式：

```bash
ssh achilean@100.102.51.64 "systemctl show murayama-goodjob.service -p Environment"
ssh achilean@100.102.51.64 "sudo journalctl -u murayama-goodjob.service -n 30 --no-pager"
```

正常啟動 log 會出現：

```text

```

## 後台與圖片流程

1. 後台 `/admin/` 透過 API 修改作品、相簿與帳號。
2. 作品資料寫入 PostgreSQL。
3. 圖片上傳時，server 轉 WebP 後透過 `rclone` 上傳到 R2。
4. PostgreSQL 只存圖片 URL、順序與作品關聯，不存圖片 binary。
5. 前台圖片直接走 `goodjob-img.weddingwishlove.com` CDN。

## 備份與還原

PostgreSQL 已納入主機每日備份鏈路。備份服務：

```text

host-gdrive-backup.service
```

正式變更前如需手動備份：

```bash
ssh achilean@100.102.51.64 "pg_dump goodjob_site > /srv/weddingwish/goodjob-sit/data/goodjob_site.pre_change_$(date +%Y%m%d_%H%M%S).sql"
```
