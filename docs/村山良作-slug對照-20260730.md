38 篇「8 位 hex 亂碼 id」作品的語意化網址對照，供村長審名。

- **id 不改**：id 同時是 R2 圖片路徑（`goodjob-img.weddingwishlove.com/works/{id}/…`）
  與前端 hash routing（`#detail/{id}`）的 key，動了就破圖。
- **只加 slug 欄位**：`/works/{slug}` 正常 200；舊的 `/works/{id}` 301 轉到新網址，
  舊連結與已被索引的網址都不會壞。
- **另外 26 篇 id 已語意化的作品不填 slug**，網址維持原狀、不產生無謂 301。
- 落庫用 `scripts/add-slug-20260730.sql`。

## 命名原則

1. 全小寫英文 kebab-case，3~6 個詞，含品牌／場景關鍵語意。
2. 專有名詞沿用站內慣例：`nccu`（政大）、`qijiaban`（企家班）、`qijibang`（奇技邦）。
3. **戶政類例外**：沿用站內既有 6 篇的 `{區名拼音}-civil` 慣例（`daan-civil`、
   `datong-civil`、`nuannuan-civil`、`renai-civil`、`zhongshan-civil`、
   `zhongzheng-civil`），因此為 2 個詞、不帶場景名（不寫成
   `qidu-civil-sakura-rail`）。這是刻意選擇「與既有 6 篇一致」而非「湊滿 3~6 詞」，
   若村長偏好把場景寫進網址，這 8 篇可整批改（連同既有 6 篇一起改才會一致）。
4. 基隆／北市同名區加 `keelung-` 前綴區分：`xinyi-civil`（北市信義）對
   `keelung-xinyi-civil`（基隆信義）；`zhongzheng-civil`（北市中正，既有）對
   `keelung-zhongzheng-civil`（基隆中正）。其餘基隆區沿用不加前綴的既有慣例。
5. 38 個 slug 彼此不重複，且與現有 64 篇的任何 id 都不撞名（已對線上
   `/api/articles` 全集核對）。
