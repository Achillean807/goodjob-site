## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| 廣域覆蓋 production | `scp -r *`、主機 `git pull` 或未排除 runtime 的同步曾造成資料災難 | blocking | 只部署明確列出的變更檔；先備份被替換檔案，前後查 PostgreSQL 三項筆數 |
| 在 WSL 直接呼叫 ssh | 本 session 第一次遠端唯讀檢查再次因金鑰不可用失敗 | blocking | 直接使用 Windows OpenSSH 絕對路徑並先跑唯讀 service/DB 檢查 |
| 把圖片清單當作 articles 欄位 | 查詢 `articles.images` 實測失敗；正式 schema 把圖片拆在 `article_images` | advisory | 作品數查 `articles`，圖片數查 `article_images`，帳號數查 `accounts` |
| 無環境變數直接啟本機 server | `server.py` 會因缺 `GOODJOB_DATABASE_URL` fail-fast | advisory | 本機 smoke test 用獨立暫存 DB：`GOODJOB_ALLOW_SQLITE=1 GOODJOB_DB_PATH=/tmp/.../goodjob.sqlite3` |
| 假設 jq 已安裝 | JSON-LD 驗證時 `jq: command not found` | advisory | 用 `python3 -m json.tool` 驗證 JSON，數量再用 `rg` 統計 |
