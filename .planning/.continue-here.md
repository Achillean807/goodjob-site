## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| 廣域覆蓋 production | `scp -r *`、主機 `git pull` 或未排除 runtime 的 rsync 曾造成資料災難 | blocking | 只用經過 entry guard 的 `git archive`；先備份 DB，再解壓到明確站台路徑 |
| 在 WSL 直接呼叫 ssh | 本 session 第一次 SSH 因金鑰不可用而失敗 | blocking | 固定使用 Windows OpenSSH 絕對路徑；先跑唯讀 `hostname`/`systemctl is-active` 驗證 |
| 假設 Linux Playwright 可用 | `playwright-cli` 找不到 `/opt/google/chrome/chrome`；Codex browser bridge 也因 WSL `sandboxCwd` 失敗 | advisory | 視覺驗收使用 Windows Chrome `chrome.exe --headless=new --screenshot=...`，或先安裝可用 Chrome runtime |
